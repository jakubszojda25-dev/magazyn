# Magazyn SAFETY – Piotr Szojda

Aplikacja magazynowa: stan, przypisywanie towaru do firm, odhaczanie dostaw, historia i dziennik zmian.

- Adres: https://safetymagazynszojda.web.app
- Backend: Firebase (projekt `magazyn-f870c`) – logowanie e-mail/hasło, baza Firestore.
- Każdy push do gałęzi `main` automatycznie wgrywa stronę na Firebase Hosting (`.github/workflows/firebase-hosting.yml`).

Szczegóły i zarządzanie kontami: [INSTRUKCJA.md](INSTRUKCJA.md).
